# Документация проекта

Данный раздел содержит проектную документацию, историю развития архитектуры и технические спецификации.

## Структура документации

- **[Миграция на Next.js и FSD](migration/README.md):**
  - **[История миграции](migration/history.md):** полный хронологический отчёт по этапам 0–5 (от фиксации baseline до финализации релиза).
  - **[Архитектурные решения (ADR)](migration/decisions.md):** обоснование выбора App Router, FSD, next-intl, управления темой, серверной модели проектов и стратегии визуального тестирования.
  - **[Верификация и тестирование](migration/verification.md):** протоколы прогона визуальных тестов (233 эталонных снимка), smoke-тестов и проверок окружения.
  - **[Конфигурация эталона](migration/baseline.json):** хеши исходного коммита и параметры исходной среды.
