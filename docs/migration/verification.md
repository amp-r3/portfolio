- Исходные `pnpm build` и `pnpm lint` проходят в detached worktree с оригинальным frozen lockfile. Существующее предупреждение Vite: JS-чанк больше 500 kB.
- `pnpm install --frozen-lockfile` нового приложения проходит без изменения lockfile.
- `pnpm typecheck` и `pnpm lint` нового приложения проходят. Lint сообщает об устаревшей справочной таблице `baseline-browser-mapping`; зависимости не обновлялись ради подавления этого уведомления.
- `pnpm test:architecture`: 12 проверок проходят, включая запреты импортов вверх, между слайсами, в legacy и в обход публичного API через относительные пути и алиасы.
- `pnpm build`: production-сборка Next.js проходит с проверкой TypeScript. `/` и 404 предварительно рендерятся, `/project/[id]` обрабатывается сервером. Серверный runtime сохранён.
- Chromium 156.0.8078.4, Firefox 157.0, WebKit 27.2: по 5 smoke-проверок проходят (15 суммарно). Проверены прямой вход, refresh, client navigation, back/forward, HTTP 404, восстановление на главную, метаданные и публичные ресурсы.

Повторный полный прогон сравнил существующие кадры без отличающихся пикселей; все шесть функциональных проверок baseline прошли (одну проверку истории повторили отдельно после изоляции сценариев якорей).
- `pnpm baseline:record`: два видео, mobile 375×812 и desktop 1440×900, завершились успешно; сохранены переходы, прокрутка, переключение темы и мобильное меню.
- Sass Module временной пробной страницы попал в CSS production-сборки Next.js. Пробная страница удалена; после этого повторная чистая сборка показала только `/`, `/_not-found` и `/project/[id]`.
- Финальные `pnpm typecheck`, `pnpm lint`, `pnpm test:architecture` и Chromium smoke проходят. ESLint оставляет информационное уведомление об устаревшей таблице `baseline-browser-mapping`.

## Особенности окружения проверки

Для серверов, браузеров и дочерних процессов сборки использовался запуск вне ограниченной песочницы. Внутри неё build не смог прочитать вывод дочернего TypeScript, а browser preview не запустился; это ограничения среды, а не исключения из проверок приложения.

Системная установка библиотек Firefox/WebKit через `playwright install-deps` потребовала недоступного sudo-пароля. Для проверки библиотеки Ubuntu были скачаны через `apt-get download` и распакованы в `/tmp/portfolio-playwright-libs`, без изменения установленных системных пакетов. Firefox запускался с `LD_LIBRARY_PATH`; WebKit — через временную обёртку `/tmp/portfolio-webkit.sh` и временную конфигурацию `/tmp/portfolio-webkit.config.ts`, поскольку штатная обёртка перезаписывает `LD_LIBRARY_PATH`. Использовались исходные скачанные бинарные файлы Playwright. Ни один тест не был пропущен для получения успешного smoke-результата.

На обычной машине для воспроизведения достаточно установить системные зависимости штатной командой из README и выполнить `pnpm test:smoke`.

Визуальные проверки выполняются последовательно, без одновременной сборки Next.js: параллельные тяжёлые процессы в этой среде вызывали нехватку памяти и таймауты. Для PNG используется Chromium Headless Shell 156.0.8078.4 из закреплённого Playwright 1.64.1.
