# Миграция: этапы 0–1

## Эталон

Исходный коммит: `1ba5927996ee783577c6d6c38ad69796f6afea4c`.
Окружение и SHA-256 исходного lockfile закреплены в [baseline.json](baseline.json).
Используются Node.js 24.15.0 и pnpm 10.33.3. Все команды выполняются из корня репозитория.

```bash
nvm use
pnpm install --frozen-lockfile
pnpm exec playwright install chromium firefox webkit
pnpm baseline:prepare
pnpm baseline:start
```

`baseline:prepare` создаёт detached worktree в `.worktrees/portfolio-baseline`, устанавливает его собственный lockfile, собирает и проверяет исходное приложение. Вывод сохраняется в `artifacts/baseline/{build,lint}.log`. `baseline:start` запускает production preview на http://127.0.0.1:4173 и проверяет SHA, чистоту checkout и контрольную сумму lockfile. Порт должен быть свободен. Эталон не использует зависимости основного приложения.

## Скриншоты и движение

```bash
pnpm baseline:capture
pnpm test:visual
pnpm baseline:record
```

Playwright самостоятельно запускает и останавливает preview; отдельно запущенный `baseline:start` перед тестами нужно остановить. Для сравнения закреплён Chromium из Playwright 1.64.1 на Ubuntu 24.04.4 LTS x64, DPR 1, timezone Asia/Tashkent, browser locale en-US. Дата фиксируется через `setFixedTime`, таймеры продолжают работать.

Основная матрица — 90 сочетаний: пять маршрутов, три языка, две темы и три viewport. Главная снимается в пяти положениях: Hero, Skills, Projects, Contact, Footer. Дополнительно снимаются граничные ширины, hover/focus, прокрученный Header и мобильное меню. Язык выбирается существующим переключателем. Селекторы не зависят от хэшей CSS Modules.

Перед статическими кадрами загружаются шрифты и изображения, завершаются reveal-анимации; бесконечные анимации ставятся на паузу в нулевой фазе. Видеозапись использует обычные анимации. Маски секций и допуск на отличия пикселей не используются.

PNG находятся в `tests/visual/baseline` и сохраняются в Git. `baseline:capture` создаёт файлы исключительно с флагом `wx`: существующие эталоны не перезаписываются даже этой командой. `test:visual` не создаёт отсутствующие эталоны и не принимает новые снимки автоматически. При несовпадении сохраняются actual/expected/diff, overlay и trace в `artifacts/visual` и HTML-отчёт в `artifacts/visual-report`. Видео лежат в `artifacts/baseline/videos`, вне Git.

Для этапов 2–3 предусмотрено `VISUAL_TARGET=candidate pnpm test:visual`: используются локализованные адреса Next.js на порту 3000 и те же имена эталонов. Каркас этапа 1 намеренно ещё не проходит это сравнение.

## Проверки исходника и известные особенности

- `pnpm build` и `pnpm lint` проходят после frozen-установки. Vite предупреждает о JS-чанке больше 500 kB; это существующее предупреждение, не регрессия миграции.
- Без сохранённой настройки тема dark при обеих системных темах. Сохранённая тема влияет на desktop/mobile изображения проектов.
- Язык по умолчанию en, сохраняется при SPA-переходе, сбрасывается после полной загрузки страницы; язык не отражается в URL.
- Неизвестный проект и URL показывают интерфейс 404, но SPA preview отвечает HTTP 200.
- Якоря Header на странице проекта не переходят к секциям главной: целевые элементы отсутствуют.
- Возврат использует историю браузера; при прямом входе fallback на главную отсутствует.
- Логотипы с `href=""` перезагружают текущий адрес.
- Кнопка меню не имеет доступного имени. Тест использует её структуру SVG; улучшение доступности не включено в миграцию.
- Код темы ищет глобальную `.gradientLayer`, тогда как градиентные слои имеют классы CSS Modules; предполагаемая остановка градиентов при переключении темы может не применяться.
- Footer присутствует только на главной. Для denied localStorage содержимое остаётся доступным; сообщения в console о невозможности сохранения настройки ожидаемы.

Эти особенности записываются как исходное поведение; их исправления требуют отдельных задач.
